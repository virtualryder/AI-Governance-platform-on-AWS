# Customer-facing pack

SA-delivered artifacts for running the POC *with* a buyer (SLG / HCLS). Use them in this order:

1. **[VALUE.md](VALUE.md)** — one-page value overview: the problem, what the platform is, the five
   security questions it answers with a demonstrable "no", and why a regulated buyer says yes to the pilot.
2. **[DEMO-TALKTRACK.md](DEMO-TALKTRACK.md)** — a ~20-minute live demo script (Say / Show / The point)
   on the citizen-311 use case, driven by the acceptance harness.
3. **[LIMITS.md](LIMITS.md)** — honest scope + explicit exclusions, each mapped to its production step.
   Share it; the honesty is part of the sell.

These are **customer-shareable** and branding-neutral (no customer names or account IDs). They stay
consistent with the engineering record in [`../REMEDIATION.md`](../REMEDIATION.md) and the concepts in
[`../CONCEPTS.md`](../CONCEPTS.md) — update them together if the maturity or exclusions change.
